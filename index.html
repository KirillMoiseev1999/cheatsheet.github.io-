🔤 2. Заголовки (Иерархия текста)
<h1>Главный заголовок (1 раз на страницу)</h1>
<h2>Подзаголовок раздела</h2>
<h3>Подзаголовок внутри раздела</h3>

Правило для журналиста: <h1> используется только 1 раз на странице (это название статьи/сайта). <h2> и <h3> помогают поисковикам (Яндекс, Google) понимать структуру вашего текста.

📋 4. Списки (Маркированные и нумерованные)
<!-- Маркированный список (точечки) -->
<ul>
  <li>Первый пункт списка</li>
  <li>Второй пункт списка</li>
</ul>

<!-- Нумерованный список (цифры) -->
<ol>
  <li>Шаг первый</li>
  <li>Шаг второй</li>
</ol>

Маркированный список (факты):

  • Первый пункт списка
  • Второй пункт списка

Нумерованный список (инструкция):

  1. Шаг первый
  2. Шаг второй
Совет журналисту: Списки идеально подходят для рубрик «5 фактов» или «Топ-3». Они делают текст структурированным и удобным для чтения.
🔗 5. Ссылки (Главный инструмент интернета)
<!-- Ссылка, которая откроется в новой вкладке -->
<a href="https://vk.com" target="_blank">
  Текст, по которому нужно кликнуть (Например: "Мой ВК")
</a>

Текст, по которому нужно кликнуть (Например: "Мой ВК")

Атрибут: target="_blank" заставляет браузер открыть ссылку в новой вкладке. Это критически важно для журналистов, чтобы читатель не ушел с вашего сайта навсегда!

🎯 7. CSS Селекторы (Кому применяем стиль)
/* По тегу (все абзацы) */
p { color: blue; }

/* По классу (ставим точку!) */
.important { font-weight: bold; }

/* По ID (ставим решетку!) */
#header { background: black; }

Как это работает в HTML:

<p>Синий текст (по тегу <code>p</code>)</p>

<p class="important">Жирный текст (по классу)</p>

<div id="header">Черный фон (по ID)</div>

Важно: Класс (class) можно использовать много раз. ID — только один раз на странице.
📦 8. Блочная модель (Как устроен любой блок)
<!-- HTML -->
<div class="box-model">
  <div class="inner-content">
    Content (Контент)
  </div>
</div>

/* CSS стили */
.box-model {
  border: 4px solid #6E6DCC; /* Рамка (Толщина, стиль, цвет) */
  padding: 24px; /* Воздух внутри рамки */
  margin: 10px 0; /* Дистанция снаружи (сверху/снизу) */
  border-radius: 8px; /* Скругленные уголки */
}

.inner-content {
  background: #E6E9FF;
  padding: 15px;
}
Content (Контент)
Текст или картинка внутри
Border (Рамка) Padding (Внутр. отступ) Margin (Внешн. отступ)
🧱 9. Flexbox (Выстраиваем элементы в ряд)
/* HTML: Родительский контейнер (flex-container) */
<div class="flex-container">
  <div class="flex-item">1</div>
  <div class="flex-item">2</div>
  <div class="flex-item">3</div>
</div>

/* CSS стили для контейнера (.flex-container) */
.flex-container {
  display: flex; /* Включает флекс-режим */
  gap: 12px; /* Расстояние между элементами */
  justify-content: space-between; /* По краям контейнера */
  align-items: center; /* По вертикали в центре */
  flex-direction: row; /* Направление ряд (по умолчанию) */
}

/* Стили для самих элементов (.flex-item) */
.flex-item {
  background: #6E6DCC;
  padding: 12px 24px;
}

Свойства Flex-контейнера:
flex-direction: row (в ряд) или column (в столбик).
justify-content: center / space-between (по горизонтали).
align-items: center / flex-start (по вертикали).

💡 11. Полезные советы для журналистов

🦴 F12 — Рентген сайта

Нажмите F12 в браузере. Откроется панель разработчика. Вы можете подсмотреть цвет заголовка или шрифт на любом сайте.

📧 E-mail рассылки

Верстая письмо, используйте тег <table>, а не <div>. Почтовики (Gmail, Mail) ломают <div>, но любят таблицы.

🖼️ Инфографика

Поисковики не читают текст, нарисованный на картинках. Дублируйте ключевые мысли обычным текстом под инфографикой.

⚡ Не забывайте закрывать теги

Любой тег — парный. Открыли <div> — поставьте </div>. Если забудете, весь код ниже сломается.
